# Iron Empire – Fitness Website

## Project Overview

Iron Empire is a fitness website designed to create a motivating and welcoming online space for people who want to improve their physical fitness, strength, confidence and overall lifestyle.

The website provides users with information about Iron Empire, including its vision, mission, membership options, fitness team, reasons to choose the gym, and contact information. The website is designed to encourage visitors to take the first step towards their fitness journey.

Iron Empire is based on the idea that fitness is not only about building physical strength. It is also about developing discipline, confidence, consistency and a positive mindset.



## About the Developer

My name is Owami Khanyile, and I am the developer of the Iron Empire website.

I come from a very small town, and this project was an opportunity for me to combine my interest in technology with an idea that can have a positive impact on people's lives.

I wanted to create a fitness website that feels motivating and welcoming rather than making people feel judged about their bodies or their current level of fitness.

One of the ideas behind Iron Empire is that people should be able to feel more confident in their bodies and proud of their progress. Everyone starts somewhere, and fitness should be about personal growth rather than comparing yourself to other people.

Through this project, I also wanted to develop my own skills in website design and development. Creating the website allowed me to practise HTML and CSS while learning more about navigation, page structure, responsive design, visual presentation and organising a multi-page website.

The project represents both a learning experience and a creative expression of how I believe a fitness brand could encourage people to become stronger and more confident.



## Purpose of the Website

The main purpose of the Iron Empire website is to:

- Provide information about the gym.
- Introduce visitors to the Iron Empire brand.
- Explain the gym's vision and mission.
- Present available membership options.
- Introduce the fitness team.
- Explain why people should consider joining.
- Provide contact and location information.
- Encourage people to begin or continue their fitness journey.
- Create a motivating and professional online experience.



## Website Pages

The website contains the following pages:

### Home
The home page introduces the Iron Empire brand and provides the main entry point to the website.

### About Us
Provides information about Iron Empire, what the gym represents and the values behind the brand.

### Vision
Explains the long-term vision of Iron Empire and what the gym aims to achieve.

### Mission
Describes the purpose of Iron Empire and how the gym aims to support its members.

### Why Choose Us
Explains some of the reasons visitors may choose Iron Empire as their fitness environment.

### Membership
Displays the different membership options available to members.

### Meet the Empire Team
Introduces the people responsible for helping members with their fitness goals.

### Did You Know
Provides interesting fitness-related information to make the website more engaging.

### Contact Us
Provides contact information, social media information, gym hours and the gym's location.

### Join Now
Provides visitors with an opportunity to take the next step towards becoming an Iron Empire member.



## Technologies Used

The website was developed using:

- **HTML5** – used to create the structure and content of the website.
- **CSS** – used to style the website, including colours, layouts, typography, spacing, navigation and responsive design.
- **Visual Studio Code** – used as the development environment.
- **Live Server** – used to preview and test the website in a web browser.
- **Google Maps** – used to provide visitors with access to the gym's location.

## Running the Website

To run the website:

1. Open the Iron Empire project folder in Visual Studio Code.
2. Make sure all HTML files and the CSS stylesheet are located in the correct project folder.
3. Open `index.html`.
4. Use the Live Server extension in Visual Studio Code.
5. The website will open in a web browser.
6. Use the navigation links to move between the different pages.
